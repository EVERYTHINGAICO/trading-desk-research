# Evidence Gates

These gates prevent software correctness, statistical evidence, and operational performance from being collapsed into one claim.

| Gate | Required evidence | Failure consequence |
| --- | --- | --- |
| G0 Protocol | Registered hypothesis, model universe, estimand, analysis and decision rules | Exploratory classification only |
| G1 Causality | As-of timestamps, no leakage, immutable inputs, provenance checks | Experiment invalidated |
| G2 Reproducibility | Clean environment rebuilds signed outputs from manifest | No confirmatory claim |
| G3 Statistical calibration | Methods recover known truth and error rates on synthetic controls | Validation engine blocked |
| G4 Historical confirmation | Purged evaluation, dependence correction, multiple-testing control, costs and negative controls | Strategy not promoted |
| G5 Prospective Shadow | Frozen version, independent event sample, track length and stable attribution | Continue collecting or reject |
| G6 Demo execution | Reconciled fills, fees, funding, latency, protection and failure accounting | Operational promotion blocked |
| G7 Independent reproduction | Independent rerun within declared numerical and substantive tolerances | Claim remains unverified |

## Candidate Confirmatory Quantities

The registered protocol must justify thresholds for:

- effect size and confidence interval;
- Deflated Sharpe Ratio;
- Probability of Backtest Overfitting;
- White Reality Check or SPA p-value;
- False Discovery Rate;
- Minimum Track Record Length;
- effective independent event count;
- maximum drawdown and cost-stress stability.

Values are intentionally not hard-coded here. Thresholds depend on the estimand, sampling process, dependence structure, model universe, and cost of false promotion. Choosing thresholds after observing outcomes is prohibited.

## Claim Vocabulary

- **Software verified:** specified tests passed.
- **Causally reconstructed:** required timing and provenance checks passed.
- **Historically supported:** preregistered historical evidence passed G0-G4.
- **Prospectively supported:** frozen forward evidence passed G5.
- **Operationally observed:** reconciled Demo evidence passed G6.
- **Independently reproduced:** G7 passed.

None of these terms means guaranteed profitability or approval for live capital.
