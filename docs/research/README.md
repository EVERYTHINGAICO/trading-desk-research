This directory is the normative entry point for scientific claims made by the Everything AI Co Trading Desk Research System.

## Current State

- Program maturity: design and governance.
- Highest strategy evidence class: `E1` exploratory.
- Confirmatory experiments registered: zero.

These statements are intentionally conservative. Software tests, Demo deployment, and positive account movement do not increase a strategy's evidence class.

## Rules For Humans And AI Agents

- Never infer edge from software tests, replay results, Demo activation, or dashboard balance.
- Never call a legacy experiment preregistered.
- Never omit a failed, abandoned, or superseded variant from the model universe.
- Never tune against a locked test set or prospective outcome.
- Never count correlated legs as independent observations without a declared dependence model.
- Never promote evidence by changing terminology; promotion requires the documented gate.
- Preserve negative results and amendments permanently.
- State assumptions, uncertainty, limitations, and evidence class beside every result.

## Contribution In One Sentence

The proposed contribution is a falsifiable, provenance-first protocol that measures and controls false strategy promotion under temporal dependence, multiple research attempts, realistic execution costs, and prospective evidence collection.
