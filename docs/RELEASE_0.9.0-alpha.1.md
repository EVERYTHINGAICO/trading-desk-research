# Release 0.9.0-alpha.1 - Public Product Alpha

This is the first externally consumable alpha of the Everything AI Co Trading Desk Research System.

## Product Baseline

- Reproducible Python 3.13 installation through `pyproject.toml`.
- Clean-checkout verification and GitHub Actions test execution.
- Shadow research and explicitly gated Binance Futures Demo execution paths.
- Multi-strategy attribution, protection, reconciliation, reporting, and dashboard components.
- Dashboard bound to localhost by default.
- Apache License 2.0, attribution notice, trademark policy, security policy, and financial disclaimer.

## Validation Boundary

The software test suite validates selected system behavior. It does not prove profitability, statistical edge, live-market fitness, or safety for real capital. All included strategies remain experimental.

## Version Separation

- Product version: `0.9.0-alpha.1`
- Python package version: `0.9.0a1`
- Strategy versions: independent identifiers stored with their evidence
- Configuration versions: immutable SHA-256 hashes

Historical internal release notes are retained as engineering records and do not supersede this public product version.
